Paddlefish OS - Install from this live media
=============================================

This is a Fedora live session with the Paddlefish OS installer bundled at
/paddlefish (repo + OS images). The OS images are on this media, so you do NOT
need to configure networking to install.

Steps
-----
1. Boot this USB/ISO. You land in a lightweight Xfce desktop.
2. Open a terminal.
3. Install the OS you want:

       cd /paddlefish
       sudo ./install-to-disk.sh desktop     # or: laptop | server

4. Pick the target whole disk and type YES when asked (it will be erased).
5. Reboot when it finishes.

Notes
-----
- If your registry differs from the baked default, run instead:
      sudo PADDLEFISH_REGISTRY=ghcr.io/<owner> ./install-to-disk.sh desktop
  (Only needed later for `bootc upgrade`; not needed for this install.)
- The first real boot of the installed system forces you to set a new
  password for the default user `user` (initial password: paddlefish).
- Full documentation: /paddlefish/system_files/all/usr/share/doc/paddlefish/INSTALLING.md
